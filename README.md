# PixelHub 0.3.0

Przeglądarkowa gra logistyczna w pixel arcie. Przyjmujesz dostawy, planujesz ruch paleciaków, rozbudowujesz magazyn i realizujesz wysyłki w kampanii 30 rund.

- [GitHub Pages](https://kozackybohun.github.io/PixelHub/)
- [Wersja 0.3 na Sites](https://pixelhub-03-marcin.marcintrendziuk.chatgpt.site)
- [Tryb deweloperski na Pages](https://kozackybohun.github.io/PixelHub/?dev=1)

Lokalnie, z Node.js 24:

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Tryb deweloperski pozwala wybrać rundę 1–30 i odtworzyć jej rzeczywisty stan początkowy. Używa oddzielnego klucza zapisu w tej samej przeglądarce.
